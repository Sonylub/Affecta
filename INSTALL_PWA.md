# Установка PWA для Affecta

## Быстрый старт

PWA уже настроен и готов к использованию! Осталось только создать иконки.

## Создание иконок (обязательно для production)

### Вариант 1: Автоматическая генерация

```bash
# Установите библиотеки
pip install cairosvg pillow

# Перейдите в папку с изображениями
cd static/images

# Запустите скрипт
python generate_icons.py
```

### Вариант 2: Онлайн-генератор (самый простой)

1. Откройте https://realfavicongenerator.net/
2. Загрузите файл `static/images/favicon.svg`
3. Скачайте сгенерированные иконки
4. Переименуйте их в формат `icon-{size}x{size}.png`
5. Поместите в папку `static/images/`

Нужные размеры:
- icon-72x72.png
- icon-96x96.png
- icon-128x128.png
- icon-144x144.png
- icon-152x152.png
- icon-192x192.png
- icon-384x384.png
- icon-512x512.png

## Проверка работы PWA

1. Запустите приложение:
   ```bash
   python wsgi.py
   ```

2. Откройте в браузере: http://localhost:5000

3. Откройте DevTools (F12) → вкладка Application

4. Проверьте:
   - Manifest загружен
   - Service Worker зарегистрирован
   - Иконки доступны

## Установка на устройства

### Android
1. Откройте приложение в Chrome
2. Меню → "Установить приложение"

### iOS
1. Откройте в Safari
2. Поделиться → "На экран «Домой»"

### Desktop
1. Иконка установки в адресной строке
2. Или меню → "Установить Affecta"

## Важно для production

⚠️ PWA требует HTTPS!
- На localhost работает без SSL
- Для production настройте SSL сертификат
